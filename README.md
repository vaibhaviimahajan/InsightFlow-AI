# InsightFlow-AI


An AI-powered Multi-Agent Data Analytics platform that automates the complete analytics workflow—from data cleaning to business recommendations.

Instead of relying on a single AI model, InsightFlow AI uses specialized agents that collaborate to analyze datasets, generate visualizations, uncover insights, and produce actionable business recommendations.

---

## ✨ Features

- 📂 Upload CSV datasets
- 🧹 Automatic data cleaning
- 📊 Exploratory Data Analysis (EDA)
- 📈 Intelligent chart generation
- 💡 AI-generated business insights
- 🎯 Data-driven recommendations
- 💬 Chat with your dataset
- 📄 Export professional PDF reports

## 📌 Agent Workflow

### Data Cleaning Agent
- Handle missing values
- Remove duplicates
- Standardize data
- Fix data types
- Detect outliers

### EDA Agent
- Summary statistics
- KPI generation
- Correlation analysis
- Category analysis
- Trend detection

### Visualization Agent
- Automatically selects the best charts
- Histograms
- Heatmaps
- Scatter plots
- Line charts
- Bar charts

### Insight Agent
Converts raw statistics into business-friendly insights.

### Recommendation Agent
Generates actionable recommendations based on analytical findings.
